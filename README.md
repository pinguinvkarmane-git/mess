# Company Messenger

Небольшой отдельный сайт-мессенджер для команды компании. Он запускает HTTP-сервер, отдаёт веб-интерфейс, держит realtime-чат через WebSocket и сохраняет историю сообщений в папку `data/`.

## Возможности

- общие каналы для команды;
- realtime-сообщения без перезагрузки страницы;
- список пользователей онлайн;
- индикатор набора текста;
- сохранение истории сообщений на сервере;
- опциональный код доступа для сотрудников;
- без внешних npm-зависимостей.

## Запуск локально

Нужен Node.js 18 или новее.

```powershell
node server.js
```

Откройте:

```text
http://localhost:3000
```

Для доступа коллег внутри локальной сети запускайте сервер на компьютере или VPS, доступном всем сотрудникам, и откройте:

```text
http://IP-АДРЕС-СЕРВЕРА:3000
```

## Код доступа компании

Если нужен общий пароль для входа, задайте переменную окружения:

```powershell
$env:MESS_COMPANY_CODE="секретный-код"
node server.js
```

Без этой переменной сайт пропускает пользователей только по имени.

## Проверка

```powershell
node scripts/smoke-test.js
```

Тест поднимает временный сервер, подключает двух WebSocket-клиентов и проверяет доставку сообщения.

## Деплой

Для постоянной работы лучше разместить проект на VPS или внутреннем сервере компании:

```powershell
git clone https://github.com/pinguinvkarmane-git/mess.git
cd mess
$env:MESS_COMPANY_CODE="ваш-код"
$env:PORT="3000"
node server.js
```

Для публичного доступа используйте HTTPS и reverse proxy, например Nginx или Caddy. WebSocket должен проксироваться на тот же порт.

## Структура

```text
server.js              сервер, WebSocket и хранение истории
public/index.html      интерфейс мессенджера
public/styles.css      внешний вид
public/app.js          логика клиента
scripts/smoke-test.js  быстрая проверка realtime-сообщений
```
